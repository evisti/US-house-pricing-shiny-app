# US House Pricing App

The app explores the 'For sale-listings' dataset from the American online real estate marketplace [Zillow](https://www.zillow.com/research/data/). 
It uses the data for 'For-Sale Inventory', 'New Listings', and 'Median List Price' (format: smooth, monthly, all homes).
